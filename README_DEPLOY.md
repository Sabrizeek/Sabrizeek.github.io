## GitHub Pages setup (Windows, without command line)
1. Open https://github.com/new and sign in to the account **Sabrizeek**.
2. In **Repository name**, enter exactly `Sabrizeek.github.io`. Set **Public** and click **Create repository**.
3. Unzip the supplied `BA_Portfolio_Website_Publish.zip` on Windows. Open the extracted folder.
4. From the new GitHub repository choose **Add file > Upload files** (or **uploading an existing file** if the repository is empty).
5. Upload the **contents** of the folder: `index.html`, `assets/`, `projects/` and `documents/` (not the zip file itself). Keep folder paths intact. Commit the upload.
6. Select **Settings > Pages > Build and deployment > Source: Deploy from a branch**. Choose `main` and `/(root)`, then **Save**.
7. Once GitHub Pages reports success, open https://sabrizeek.github.io/ . Test the CV button, both downloadable case-study PDFs, workflow images, and every card.

**Important:** The CV intentionally links to https://sabrizeek.github.io/ . Publish the website before sending the CV to recruiters so the link works.
